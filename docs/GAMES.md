# Supported games

VOLT is one app with one familiar way to manage mods and load orders, whichever game you play. This page lists every game VOLT supports or plans to support.

| Game | Status | Mod source | Since |
| --- | --- | --- | --- |
| RimWorld | Available | Steam Workshop | 0.1.0 |
| Valheim | Available | Thunderstore | 0.4.21 |
| Lethal Company | Available | Thunderstore | 0.6.20 |
| R.E.P.O. | Available | Thunderstore | 0.6.47 |
| Project Zomboid | Planned | Steam Workshop | |
| Slay the Spire 2 | Planned | Steam Workshop | |
| Palworld | Planned | To be decided | |

**Status meanings.** *Available*: shipped in the latest release. *Planned*: intended, no work started that you can use yet. Planned games and their order can change.

Other games may be added later. Open an issue on the repository to suggest one.
